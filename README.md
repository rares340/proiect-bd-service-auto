# Sistem de Gestiune Service Auto & Statie ITP

## Descriere:
Aplicatie dedicata evidentei unui service auto si a liniei ITP:
- Monitorizarea intrarilor in service, devizelor de manopera si consumului de piese.
- Inregistrarea fiselor de inspectie tehnica periodica.
- Sistemul integrează un modul de Machine Learning (scikit-learn) pentru asistență la recepție: pe baza mărcii, modelului, vechimii și kilometrajului vehiculului, modelul analizează istoricul reparațiilor anterioare și sugerează automat mecanicului piesele și subansamblele cu cel mai mare risc de uzură.
