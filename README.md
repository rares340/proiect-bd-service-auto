# Sistem de Gestiune Service Auto & Statie ITP

## Descriere:
Aplicatie dedicata evidentei unui service auto si a liniei ITP:
- Monitorizarea intrarilor in service, devizelor de manopera si consumului de piese.
- Inregistrarea fiselor de inspectie tehnica periodica.
- Modul simplu de Machine Learning (scikit-learn) ce analizează istoricul reparațiilor (marcă, model, vechime, kilometraj, combustibil) și sugerează automat mecanicului piesele și subansamblele cu risc ridicat de uzură ce necesită verificare prioritară.
